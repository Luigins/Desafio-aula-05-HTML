# Desafio-aula-05-HTML]

Nesse desafio trabalhamos as tags de HTML como lista, link, imagem, cores e entre outros. Usamos todos esses conhecimentos aprendidos para criar um mini site fictício usando todas essas tags 

---

## 🚀 Funcionalidades e Destaques

- **Interface Focada em UX/UI:** Planejamento visual orientado à usabilidade, hierarquia de informações e navegação intuitiva.
- **Estruturação Semântica:** Uso de elementos do HTML5 para garantir acessibilidade e boa indexação.
- **Galeria e Recursos Visuais:** Organização de assets gráficos (`.jpg`, `.webp`) otimizados para rápida renderização.
- **Design Responsivo:** Adaptação da interface para diferentes tamanhos de tela.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

- **HTML5:** Estruturação lógica e semântica das páginas.
- **CSS3:** Estilização responsiva, layout e aplicação de paletas de cores.
- **JavaScript (ES6+):** Manipulação dinâmica de elementos e interações do usuário.
- **VS Code:** Ambiente de desenvolvimento integrado (IDE).
